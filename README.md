# Zayvora Professional Frontend V2

Responsive storefront with category filters, product detail modal, local-storage cart, quantity controls, subtotal, and WhatsApp order handoff (01815961657).

## Publish on existing Netlify site
1. Extract this ZIP on your device.
2. In Netlify, open the existing Zayvora site → Deploys.
3. Drag the extracted `zayvora-v2` folder (or its contents with `index.html` at the root) to the manual deploy area. The existing site URL remains the same.

## Important limitations
- This is a frontend demo/storefront. Product prices are sample values; no real stock database/admin, user accounts, payment processing, or server-side order records exist.
- WhatsApp handoff opens a prefilled order summary; customers must send it themselves.
- The hero image is a visual concept screenshot used as a temporary banner, not separate original product photography.
- Replace sample product emoji with actual product photos and confirm prices, weights, shipping, and policies before launch.
